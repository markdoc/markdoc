# {% $markdoc.frontmatter.title %}

This website is a lightweight starting point for a documentation site using Markdoc and the Next.js App Router.

## Quick start

Edit `app/page.md` to change this page. Add another `page.md` in a route directory, such as `app/docs/getting-started/page.md`, to create a new page.

The `title` and `description` in frontmatter automatically become the page's Next.js metadata. Add custom nodes, tags, and functions in the `markdoc` directory.

## Get started from scratch

Read the [Next.js integration guide](https://markdoc.dev/docs/examples/nextjs), explore the [Markdoc documentation](https://markdoc.dev/docs/getting-started), or copy this [example directory](https://github.com/markdoc/markdoc/tree/main/apps/docs/examples/simple-nextjs) into your own project.
